# 操作ガイド

## 接続と音作り

SYSTEM-1をUSBで接続し、Rolandの対応ドライバーを導入してください。DAWのオーディオデバイスは普段のインターフェースのまま使用します。VST3はインストゥルメントトラックへ追加します。`System1Capture.exe` がバックグラウンドでUSB音声を取り込み、プラグインがDAWのレートへ変換します。

実機のMIDIチャンネルと上部のCHを揃えます。MIDI controlは実機制御、DAW notesはDAWからの演奏情報転送です。ポートを独占するのは1インスタンスだけです。

MANUAL長押しで実機の操作子を受信します。`*` は未同期、`~` は保存値に最も近い選択肢を意味します。画面のノブやセレクターを操作すると対応CCを送り、実機の操作も画面へ反映します。

VOICE MODEはPoly / Mono / Unisonです。和音はPolyを選びます。v0.7.1で実機との対応を修正しました。過去のプロジェクトのCC値は変換せず、正しいモード名で表示します。

USB LEVELはプラグインの出力音量です。実機のVOLUMEとは独立しています。ノブ・フェーダーをダブルクリックするとプラグイン既定値へ戻ります。実機の工場出荷時音色を呼び出す操作ではありません。

Firmware 1.20の拡張波形を含む12波形を選べます。波形選択は拡張バンクを先に送ります。DAWで波形を自動化するときは波形CCと拡張バンクCCの両方を指定してください。SCATTER / ARPは実機で操作します。

## クロック

実機のMIDI Clock SourceをAUTOにします。他アプリからSYSTEM-1へクロックを重複送信しないでください。

| 選択 | 動作 |
| --- | --- |
| Clock off | クロックを送信しません。 |
| DAW tempo | DAWのBPMからMIDI Clockを送ります。DAW停止中も音声処理が続けば送信します。 |
| Tempo + transport | DAWの再生・停止にStart / Stopも連動します。 |

Clock sendingは送信側の状態です。実機の同期完了応答ではありません。クロックは四分音符あたり24パルスで、別スレッドから送ります。サンプル単位の時刻精度、任意の小節位置への完全な位置復元は保証しません。

## プリセット・ライブラリ

Preset libraryで開きます。検索、バンク選択、Favorites onlyで絞り込みます。行を選ぶだけでは音色は変わりません。

- Load preset：対応する値を読み込みます。Send to SYSTEM-1がONなら実機にも送ります。OFFなら画面へ読み込み、後で上部のSend savedから送れます。
- Save current as new：Name欄の名前で現在の既知のCCを新しいs1presetに保存します。既存ファイルの上書きではありません。一時的なMODULATION、EXPRESSION、HOLD PEDAL、USB音量、DAW clock、MIDIルーティングは保存しません。
- Rename selected / Toggle favorite：表示名とお気に入りを変更します。PRM原本は変更しません。
- Import folder：展開済みフォルダーを再帰的に取り込みます。ZIPは先に展開します。同一ファイルはスキップし、内容の異なる同名ファイルは別名で保持します。
- Export original file：選択したファイルをそのまま出力します。編集値を公式PRMへ再生成する操作ではありません。
- Archive selected：一覧から除いてArchiveへ移します。戻すときはファイルと付属meta.jsonをImported配下へ戻し、Refreshしてください。

公式PRMは49項目のCCプレビューです。8-bitから7-bitへ変換するため量子化があり、未対応のモードやARP / SCATTER等は実機の値が維持されます。公式音色の完全復元は[RolandのBACKUP / RESTORE手順](https://support.roland.com/hc/en-us/articles/201920439-SYSTEM-1-Backup-and-Restore)を使用してください。このプラグインは実機のメモリースロットへ書き込みません。

保存先は `%APPDATA%\System1Bridge\Library`。Importedは取り込み原本、Userは自作設定、Archiveは一覧から除いたファイルです。表示名とお気に入りは隣のmeta.jsonにあります。フォルダー全体をバックアップしてください。他インスタンスでの変更はRefreshで反映します。

## プロジェクト保存

受信・編集済みCC、USB音量、MIDI設定、クロック設定、折りたたみ状態をDAWプロジェクトへ保存します。ライブラリ名や保持中のノートは保存しません。読み込み時にはCCを一括送信せず、Send savedを押すと既知の値を送ります。保存したクロックモードは音声処理再開時に有効になります。

## 鍵盤とグラフ

画面鍵盤は全MIDIノート0〜127です。表示C0=MIDI 0の命名なので、中央Cの表記がDAWと異なる場合があります。クリックやドラッグでベロシティ100の演奏ができます。KEY HOLDは画面鍵盤専用です。折りたたみや画面を閉じると画面から保持したノートを解除します。Stop notesは送信したノートを停止します。

USB OUTPUT L / Rは取り込んだ実音の約20 msを、左右共通の振幅自動拡大で表示します。OSC、AD / ADSR、FILTERのGUIDEは設定に応じた模式図です。実機の波形や時間・周波数特性を測定して校正したモデルではありません。COLOR変化も表示用の近似で、CROSS MOD / RING / SYNCや実機の変調中の瞬間値は再現しません。

## トラブル対応

- 音声が無い：USB connected表示、実機の発音、Windowsの入力設定を確認します。デスクトップ上に音声アクセスの許可待ちウィンドウが出ていることもあります。
- MIDI未接続：実機の電源・USB・ドライバーを確認し、Reconnectを押します。他アプリのMIDI使用状況も確認します。
- 和音にならない：VOICE MODEがPoly、実機のMONOランプが消灯、ARPEGGIOがOFFであることを確認します。
- 書き出しで無音：高速オフライン書き出しには対応しません。ライブ音声を先にトラックへ録音します。
- 遅延：基本40 msのバッファを使用し、DAWへ約50 msを通知します。機器間クロック差へ追従しますが、往復遅延の自動実測ではありません。

問題を報告する際はOS、DAW、Rolandドライバー、実機ファームウェア、接続表示と再現手順を記載してください。
